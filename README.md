# Flameworks 상품 단가표

사이트는 첨부된 단가표를 바탕으로 PC에서는 표, 모바일에서는 상품별 카드로 표시합니다. 단가와 재고를 수정하는 곳은 Google Sheets의 data 탭입니다.

## 시트 연결

현재 연결된 시트 주소는 아래와 같습니다.
https://docs.google.com/spreadsheets/d/1GakBnRrG4DS02deVaHGvE70LpP9qo0HOdf6ClgyhLgA/edit#gid=1714803519

기존 시트의 편집 권한이 없어 원본은 수정하지 않았습니다. 편집 권한이 있는 계정으로 data 탭을 연 뒤 catalog.csv를 파일, 가져오기에서 업로드하고 ‘현재 시트 바꾸기’를 선택하세요. 숫자와 날짜 자동 변환은 해제하면 모델명의 문자와 앞자리 0을 보존할 수 있습니다. 시트 파일 전체를 교체하거나 data 탭을 삭제하면 연결 ID가 바뀔 수 있으니 현재 탭의 데이터만 교체하세요.

열 순서는 모델, 색상, 단가, 225, 230, 235, 240, 245, 250, 255, 이미지입니다. 단가는 원 단위 숫자를 쓰고 재고 0과 미입력은 구분합니다. 합계는 사이트에서 계산합니다.

기존 컬러 묶음 형식이 남아 있는 동안만 catalog.csv의 183개 항목을 사용합니다. 새 형식을 읽은 뒤부터는 Google Sheets가 기준입니다. 통신 오류나 알 수 없는 시트 형식에서는 예전 가격으로 대체하지 않습니다.

이 파일은 외부 공개용입니다. 도착가와 내부 메모는 별도의 비공개 스프레드시트 파일에 기록하세요. 숨긴 탭이나 숨긴 열은 비공개 보관 장소가 아닙니다.

## 갱신

첫 접속, pageshow, 화면 복귀, 창 포커스, 네트워크 재연결, resume에 데이터를 새로 요청합니다. 요청마다 다른 주소와 no-store를 사용하며 상품 데이터를 localStorage에 저장하지 않습니다. 짧은 시간에 겹친 이벤트는 하나로 합치고 이전 요청 결과가 새 가격을 덮어쓰지 못하게 합니다. 시트 전환 여부만 브라우저에 저장합니다. 수동 새로고침 버튼도 있습니다.

CSS와 화면은 기존 첨부 HTML을 재사용했고 외부 라이브러리와 빌드 과정은 없습니다. index.html, css/style.css, js/app.js, catalog.csv를 같은 구조로 FTP에 올려도 사용할 수 있습니다.

## 확인 범위

Chromium의 모의 Google Sheets 응답으로 검색, 정렬, 이미지 URL 대응, 확대, 수명주기 갱신, 오류 복구, 모바일 폭을 확인했습니다. 실제 카카오톡 앱과 원격 이미지 서버는 해당 테스트에 포함되지 않았습니다.
